# BIG STROI — сайт

Одностраничный сайт мебельного производства BIG STROI (Астана). Контент и медиа взяты из Instagram @big_stroi.kz, подробности в `../BRIEF.md`.

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/ (статические файлы, подходят для любого хостинга)
npm run preview  # просмотр собранной версии
```

## Стек

- Vite + React 19 + TypeScript
- GSAP 3: ScrollTrigger, DrawSVG, SplitText, Flip (все плагины бесплатны с 2025 года), хук `useGSAP`
- Lenis — плавная прокрутка, синхронизирована со ScrollTrigger (`src/lib/useLenis.ts`)

## Анимации

| Где | Что происходит | Файл |
|---|---|---|
| Загрузка | Крыша и стены логотипа прорисовываются (DrawSVG), буквы BIG падают, STROI выезжает, логотип перелетает в шапку (Flip) | `components/Preloader.tsx` |
| Первый экран | Экран закрепляется, canvas перематывает 94 кадра «пустая комната → кухня → вечерняя подсветка», размерные линии с мм растут | `components/Hero.tsx`, `lib/frames.ts` |
| Рулетка | Жёлтая лента-метр с фактами едет вбок | `components/Tape.tsx` |
| Каталог | Фото раздела следует за курсором (только мышь) | `components/Catalog.tsx` |
| Проекты | Закреплённая горизонтальная прокрутка карточек (на мобильном — свайп) | `components/Projects.tsx` |
| До/после | Шторка между кадрами «до» и «после» идёт за прокруткой | `components/BeforeAfter.tsx` |
| Этапы | Линия прорисовывается вниз, этапы загораются | `components/Steps.tsx` |
| Производство | Ролики из цеха смещаются с разной скоростью | `components/Production.tsx` |

Все анимации учитывают `prefers-reduced-motion`: при включённой настройке показывается конечное состояние.

## Структура

- `src/data/content.ts` — все тексты, цены, контакты, отзывы
- `src/data/logoPaths.ts` — логотип в кривых (временная перерисовка, заменить на исходник клиента)
- `public/media/` — фото (WebP), видео (H.264 540p), кадры первого экрана (`seq/`), кадры «до/после» (`ba/`)
